AI 情感伴侣软件前端页面设计提示词 (UI/UX Prompt)
项目定位: 一款专注于“情感链接与长程陪伴”的 AI 交互软件。核心竞争力在于极其精细的“长记忆管理”（最大限度降低 Token 消耗）以及沉浸式的多模态交互体验。不追求生产力工具属性，追求私密性、情感共鸣和个性化定制。
目标受众: 需要情感倾诉、角色扮演陪伴、虚拟伴侣的用户。
整体风格: 温馨、私密、沉浸、极简（减少技术感和工具感）。建议采用柔和的莫兰迪色系或可随情绪变幻的动态背景。支持深色/浅色模式平滑切换。
核心页面与功能模块布局
整个应用建议采用 左右双栏结构 或 侧边抽屉式结构（在移动端或窄屏下侧边栏可收起）。
一、 核心交互区 (主界面/聊天区)
设计目标: 沉浸式对话，弱化界面边框，突出情感交流。
顶部导航栏 (Header):
角色信息: 当前人设头像、昵称（支持点击展开详细人设卡片）。
当前情感状态/好感度指示器: (可选) 用微小的动态图标（如心跳、温度计）展示 AI 当前的“情绪值”或你们的“亲密度”。
快捷操作区: 模型/API 切换快捷按钮、记忆面板呼出按钮、设置按钮。
对话展示区 (Chat History):
气泡设计: 柔和圆角，区分用户和 AI。支持打字机流式输出效果。
多模态内容渲染: 优雅地展示图片（支持点击放大查看）、播放语音消息（带音频波形动画，而非冰冷的播放条）。
上下文回溯 (时光机): 支持将界面滚动到历史消息，并提供一个“从这里开始新分支”的悬浮按钮。
多模态输入区 (Input Area):
极简输入框: 支持多行文本，自适应高度。
多模态按钮:
🎙️ 语音输入: 按住说话/点击录音，带音频输入波形反馈。
📷 图片分享: 快速上传图片（提示文案类似“分享你的生活”而非“上传文件”）。
发送按钮: 明确的发送反馈。
二、 长记忆管理控制台 (Memory Console)
设计目标: 这是整个软件的灵魂。必须让用户直观地看到、管理并压缩记忆，以最大化节省 Token。 （建议作为右侧边栏或独立覆盖页展示）。
记忆消耗仪表盘 (Token Dashboard):
可视化图表: 使用环形图或进度条，清晰展示当前上下文窗口的 Token 占用情况（分为：人设占用、核心记忆占用、近期短期记忆占用）。
预警提示: 当 Token 占用接近阈值时，给出柔和的视觉提醒。
分层记忆管理 (Hierarchical Memory):
A. 核心记忆 (Core Memories - 永久保留):
界面展示为“卡片”或“便签”。
功能：用户可手动添加绝对不能忘的事情（如“我的生日是X”、“我不喜欢吃香菜”）。此部分优先级最高，每次对话必带。
B. 提炼/归纳记忆 (Summarized Memories - 压缩 Token 的关键):
功能：列表展示 AI 自动总结的过去对话摘要。
操作：用户可以编辑摘要（手动删减不必要的形容词，极致压缩字数），或者合并多个摘要，甚至删除无关紧要的闲聊记录。
C. 短期工作记忆 (Short-term Context):
展示最近 N 轮对话。用户可勾选不希望带入下一次请求的轮次（例如刚刚发生的一段毫无意义的废话），一键“忽略”，阻止其消耗 Token。
记忆提取/遗忘操作 (Memory Actions):
一键压缩 (Summarize Now): 强制触发 AI 对近期对话进行总结并存入提炼记忆。
强制遗忘 (Forget Context): 清空短期记忆，只带着人设和核心记忆开启新对话。
三、 人设与模型配置中心 (Persona & Model Hub)
设计目标: 灵活、极客但易用的底层配置。
人设蒸馏工坊 (Persona Distillation):
上传区: 支持拖拽上传人设文件（TXT, JSON, 甚至特定格式的 PDF 设定集）。
设定编辑器: 一个大文本框，分块展示：[背景设定], [性格特征], [说话风格示例]。
人设集切换: 像切换账号一样快速切换不同的 AI 伴侣人设。
模型与 API 引擎室 (Engine Settings):
多模型支持: 下拉菜单选择常用模型 (如 GPT-4o, Claude 3.5 Sonnet, Gemini 1.5 Pro) 或自定义模型名称。
API 密钥管理: 密码框形式输入 API Key（本地存储，保障安全）。
Base URL 设置: 支持修改代理地址或本地大模型地址 (如 Ollama / LM Studio 接口)。
高级参数 (Advanced): 滑动条调节 Temperature (情感丰富度/创造力) 和 Max Tokens。
四、 关键交互细节 (UX Details)
加载反馈: 当 AI 正在思考或生成多模态内容时，不要用传统的转圈 loading，可以采用类似“对方正在输入...”或具有呼吸感的微动效。
Token 节省提示: 在用户输入大量文本前，如果检测到 Token 紧张，可以在输入框上方用微小文字提示：“当前记忆较多，建议精简输入或清理历史记忆哦”。
响应式设计: 确保在移动端（手机浏览器或 PWA）上，记忆管理面板可以方便地通过侧滑手势呼出和隐藏。
开发者/设计师备注: 请在实现时优先考虑前端状态管理的性能（如使用 Redux, Zustand 或 Context API），因为需要频繁且无缝地在“当前对话”和“记忆管理面板”之间传递和修改数据。
